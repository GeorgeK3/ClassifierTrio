# ClassifierTrio

**ClassifierTrio** is an AI course project that implements and compares various classification algorithms, including:

- **Random Forest**
- **Naïve Bayes**
- **Logistic Regression**
- **Recurrent Neural Networks (RNN)**
- **scikit-learn Implementations**

## Features

- **Custom Implementations:** In-depth understanding through coding algorithms from scratch.
- **Benchmarking:** Comparison with scikit-learn implementations and RNNs.
- **Performance Analysis:** Evaluation of each model's accuracy and efficiency.
